CSS Errors - Errores comunes

Error 1: Falta punto y coma (;)

Esta clase tiene error: color: red background-color: yellow; Solo se aplica el segundo (amarillo).

Error 2: Propiedad inválida

Error: colr: blue; (colr no existe, se ignora). Solo aplica font-size.

Error 3: Valor inválido

Error: width: -100px; (ancho negativo inválido). Solo aplica color.

Error 4: Llave sin cerrar

Error: llave } olvidada. ¡Toda la regla se ignora!

Error 5: Doble :: o extra

Error: color:: blue; (doble dos puntos). Se ignora la propiedad.

Versiones corregidas funcionan bien

Correcto 1: Con punto y coma
