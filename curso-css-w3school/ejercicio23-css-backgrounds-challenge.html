CSS Background

A background color and a background image can be set together. The color shows where the image does not cover.

Este párrafo extra muestra que el color lightblue llena donde NO cubre la imagen.

La imagen está en right top, no-repeat.

Propiedad Valor usado
background-color lightblue
background-image url('img_tree.png')
background-repeat no-repeat
background-position right top
