Ejercicio 02 - Sintaxis de CSS

Este párrafo está aquí para probar una regla CSS que centra el texto y lo pinta de rojo, usando la sintaxis básica: selector + bloque de declaraciones.

En CSS, el selector apunta al elemento HTML que quiero estilizar (por ejemplo p), y dentro de las llaves van las propiedades con sus valores, separadas por punto y coma.

Aquí estoy practicando más declaraciones en el mismo bloque, como font-size, background-color y padding, para ver cómo afectan al mismo elemento.
