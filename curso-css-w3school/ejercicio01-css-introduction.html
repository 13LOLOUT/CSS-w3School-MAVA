Probando introducción a CSS

CSS es el lenguaje que se usa para darle estilo a una página web: colores, fuentes, tamaños, márgenes, etc.

La ventaja es que, con un solo archivo CSS, puedo cambiar el look de varias páginas al mismo tiempo.

CSS Demo - Una página HTML con varios estilos

Da clic en los enlaces de abajo para cargar diferentes hojas de estilo sobre la misma página. El HTML no cambia, solo cambia el CSS.
