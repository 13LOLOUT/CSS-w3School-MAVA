External CSS (desde ejercicio06-how-to-add-css.css)

Este párrafo tiene estilos del CSS externo: fondo lightblue, h1 navy con margen.

Internal CSS (definido en <style> del head)

Este párrafo usa internal CSS: fondo lightgreen, borde verde. Es útil para estilos que solo van en esta página específica.

Inline CSS (style="" directo en el HTML)

Este párrafo tiene inline CSS. Es rápido para probar algo específico, pero no se recomienda mucho porque es difícil de mantener.

Método Ejemplo Ventaja
External <link rel="stylesheet" href="..."></td> Cambia toda la web con 1 archivo
Internal <style> en head Solo esta página
Inline style="" en elemento Rápido para 1 elemento
